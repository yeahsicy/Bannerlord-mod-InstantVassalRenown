# Bannerlord-mod-InstantVassalRenown
A custom mod making Renown at least 150 (Tier 2) to give instant Vassal option in Mount &amp; Blade II: Bannerlord. 

## Feature
It makes player's Renown at least 150 (Tier 2) to enable Vassal option instantly. 

## Compatibility
This mod is purely an add-on. Compatible with other mods except those also change player's Renown. 

It's developed based on game version 1.3.13. No testing was performed for previous versions. 
Technically, it should work in older versions as the Renown implementation seemed never changed. 

No read / write operation is made to the game save. Turning this on / off shouldn't impact the save. 

## Installation
* Unzip the downloaded file. Copy `InstantVassalRenown` folder to Bannerlord `Modules` folder.
* Open the game launcher and check this mod. 

## Troubleshoot / support
- Like other mods, it's common to see crashes / Unable to start when:
  - Running in mismatched game version (Highly unlikely in this though).
  - Having conflicts with other mods.
- This mod is just for fun and mainly my own personal use, so no promise to maintain this for later versions or support others at this stage.
- Only best efforts to GitHub Issues filed here.
